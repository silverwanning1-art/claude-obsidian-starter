# Projekte

Hier liegt je ein Code-Projekt in einem eigenen Ordner, mit eigener `AGENTS.md` (Regeln für das Projekt), einer `CLAUDE.md`, die nur auf die `AGENTS.md` verweist, und eigenem Git-Repo. Eine Coding-Session startest du im Projektordner, nicht im Workspace.

Jedes Projekt hat außerdem eine `STAND.md`: Ziel, aktueller Stand, nächster Schritt und offene Fragen auf einer Seite. {{AGENT_NAME}} liest sie zu Beginn jeder Session im Projekt und schreibt sie neu, wenn du am Ende einer Session {{SEAL}} aufrufst. So weißt du und weiß {{AGENT_NAME}} sofort, wo das Projekt steht.
