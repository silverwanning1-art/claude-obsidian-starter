# Handout

Entwurf, wird nach dem ersten Probelauf ausformuliert.

1. Vorab: [Vorab-Checkliste](Vorab-Checkliste.md) erledigt.
2. Den Ordner `workspace` in Claude Code öffnen und „los“ schreiben. Die Einrichtung fragt dich durch, zeigt einen Plan und wartet auf dein Ja.
3. Den Vault-Ordner in Obsidian öffnen („Ordner als Vault öffnen“).
4. Session beenden, eine neue starten und prüfen, ob Claude dich kennt („Was weißt du über mich?“).
5. Am Ende einer Session `/seal-session` ausprobieren.
6. Arbeitsweise: Planmodus nutzen, den Plan in einer Datei speichern und mit `/clear` frisch umsetzen. `/context` zeigt, wie voll das Kontextfenster ist, `/compact` fasst zusammen.

Hilfe bei Problemen: [Troubleshooting](Troubleshooting.md).
