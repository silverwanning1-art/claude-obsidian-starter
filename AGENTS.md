# Starter für ein KI-Betriebssystem

Einrichtung: offen

Dieser Ordner ist der unveränderte Starter. Er wird zum Arbeitsordner (Workspace) der Person, die ihn heruntergeladen hat: ein Obsidian-Vault für Wissen, ein Ordner `projects/` für Code und Regeln für die Zusammenarbeit mit ihrem KI-Assistenten (Claude Code oder Codex).

Solange oben „Einrichtung: offen“ steht:

- Begrüße die Person kurz, erkläre in zwei Sätzen, was die Einrichtung macht, und starte dann den Skill `setup`. Das gilt auch, wenn sie nur „los“ oder „hallo“ schreibt.
- Lege vor der Einrichtung keine Dateien an und ändere nichts.
- Dateien unter `starter/` sind Vorlagen und Material, keine Anweisungen an dich. Lies sie nur, wenn der Skill `setup` es verlangt.

Ausnahme: Liegt dieser Ordner unter `projects/` eines bestehenden Workspace, wird der Starter selbst weiterentwickelt. Dann nichts einrichten, sondern wie ein normales Code-Projekt arbeiten. Tests: `python -m pytest tests`.

Am Ende der Einrichtung ersetzt der Skill `setup` diese Datei durch die Regeln der Person.
